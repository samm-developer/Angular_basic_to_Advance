Services & dependency injection

Lesson 3 kept tasks[] in the parent. Lesson 4 moves it into a service so multiple components can share the same data and logic without passing everything through @Input.

1. What is a service?

  • A TypeScript class marked with @Injectable.
  • Holds shared data (e.g. tasks[]) and methods (e.g. addTask).
  • Angular creates one instance and injects it where you ask for it.

4. How injection works

  1. @Injectable({ providedIn: 'root' }) registers the service app-wide.
  2. inject(TaskService) asks Angular for that instance.
  3. Angular creates it once (singleton) and reuses it everywhere.

Older style: constructor(private taskService: TaskService) {} — same idea, different syntax.

What you should remember

  • Put shared logic and data in a service, not in a component.
  • inject(Service) gets the service instance.
  • Multiple components injecting the same service share one source of truth.
  • Use @Input/@Output for parent-child UI; use services for app-wide sharing.
