Control flow: @if and @for

In Lesson 1 you bound data to the page. Here you decide what to show and how many times — conditionally and from a list.

1. New syntax (Angular 17+)

Older Angular used structural directives like *ngIf and *ngFor. Modern Angular uses block syntax directly in the template:

  • @if — show a block when a condition is true
  • @else — optional fallback block
  • @for — repeat a block for each item in a list
  • track — tells Angular how to identify each row (important for performance)

5. Read the TypeScript side

Open lesson-02.component.ts and notice:

  • tasks is the source data for the list.
  • visibleTasks is a getter — a computed list for the template.
  • addTask() creates a new array ([...tasks, newItem]) so Angular detects the change.
  • FormsModule is imported because the template uses ngModel.

What you should remember

  • @if chooses whether to render a block.
  • @for repeats a block for each item.
  • Always use track with @for (usually an id).
  • Keep list logic in the class; keep the template focused on display.
