3. RxJS operators used here

  • Subject — manual “reload” button trigger
  • startWith — run immediately on page load
  • switchMap — cancel old request when reload is clicked
  • map — transform API data (also used in the service)
  • catchError — turn HTTP failure into error state

What you should remember

  • Observables are lazy — nothing happens until something subscribes.
  • Prefer | async in templates over manual subscribe when you can.
  • switchMap is ideal for HTTP that can be re-triggered (search, reload).
  • Combine operators in the service or component to model loading / success / error.
