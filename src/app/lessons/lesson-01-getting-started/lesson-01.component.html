Getting started: components & data binding

Angular is a TypeScript framework for building web apps as a tree of components. This page is itself a component. Change a value in the TypeScript file and watch the view update.

1. How this app boots

  1. index.html loads and contains <app-root>.
  2. main.ts bootstraps AppComponent.
  3. AppComponent renders the header and a <router-outlet>.
  4. The router loads this lesson at /lesson-1.

2. Anatomy of a component

Open these three files together. That trio is the whole component:

  • lesson-01.component.ts — class + @Component decorator
  • lesson-01.component.html — the view (this page)
  • lesson-01.component.css — styles scoped to this view

3. Lab: interpolation {{ }}

Interpolation reads a class property and prints it in the template. Angular keeps the DOM in sync when the property changes.

Hello, {{ studentName }}. You are learning {{ framework }} {{ version }}.

Edit studentName in lesson-01.component.ts, save, and this sentence updates. 

<p>Hello, {{ studentName }}.</p>

4. Lab: event binding (click)

Parentheses listen for DOM events and call a method on the class. That is how buttons talk to TypeScript.

Count

{{ count }}

<button (click)="increment()">+ Increment</button>

5. Lab: property binding [property]

Square brackets set a DOM property from a class value. Below, [disabled] and [class.active] both come from isLiked.

isLiked is currently {{ isLiked }}

<button [class.active]="isLiked" (click)="toggleLike()">

What you should remember

  • {{ value }} displays data.
  • (event) listens for user actions.
  • [property] pushes data into the DOM.
  • The component class is the source of truth for the view.
