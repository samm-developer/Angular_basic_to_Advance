HTTP & Observables

So far, task data was hard-coded in TypeScript. Real apps load data from an API. Angular uses HttpClient, which returns an Observable — data that arrives later.

1. What is an Observable?

An Observable is a stream of values over time. A single HTTP request emits one value (the response) then completes. You subscribe to receive that value.

  • HttpClient.get() → returns Observable<Task[]>
  • .subscribe({ next, error }) → runs when data arrives or fails
  • HTTP Observables complete automatically — no manual unsubscribe needed

What you should remember

  • HttpClient talks to APIs; enable it with provideHttpClient().
  • HTTP methods return Observables, not plain data.
  • Always handle loading and error in the UI.
  • Keep HTTP calls in a service, not directly in the template.
