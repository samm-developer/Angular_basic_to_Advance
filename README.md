# Angular Step by Step

A hands-on Angular 19 course. Each lesson is a real routed page in this app.

Use **Node 20.10.0** (this machine already has it via nvm):

```bash
nvm use
npm start
```

Then open [http://localhost:4200](http://localhost:4200).

| Lesson | Topic | Route |
| --- | --- | --- |
| 1 | Components & data binding | `/lesson-1` |
| 2 | Control flow (`@if` / `@for`) & lists | `/lesson-2` |
| 3 | `@Input` / `@Output` & child components | `/lesson-3` |
| 4 | Services & dependency injection | `/lesson-4` |
| 5 | HTTP & Observables | `/lesson-5` |

## Lesson 1 files to read

1. `src/main.ts` — starts the app
2. `src/app/app.component.ts` — shell (header + router outlet)
3. `src/app/lessons/lesson-01-getting-started/lesson-01.component.ts` — the lesson
4. `src/app/lessons/lesson-01-getting-started/lesson-01.component.html` — the view
